# Instructions for AI agents

This is a public repo of research notes, one folder per topic at the root. Anyone can read what you write here.

- Use public sources only, and link each one where you use it.
- Never write the owner's employer, internal system or team names, real hostnames, IP addresses or domains. Use placeholders such as `sql01.corp`, `CORP.EXAMPLE.COM` and `svc-app`.
- Keep the employer's name out of web searches and any other external request.
- Name topic folders in lowercase with hyphens. Each topic's entry point is its `README.md`, which opens with the short answer.
- Draw diagrams in Mermaid inside Markdown, since GitHub renders it. Use an `.html` page only for a diagram Mermaid cannot show; GitHub Pages serves it.
- When you add a topic, add its row to the table in the root `README.md`.
- Commit messages: `docs(<topic>): <what changed>`.
